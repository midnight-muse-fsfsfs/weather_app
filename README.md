# 🌦 Weather App

A modern weather application that displays real-time temperature
and dynamically changes background images based on the searched city.

## 🔥 Features
- Real-time weather data
- City-based background images
- Clean UI/UX design
- Responsive layout

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- WeatherAPI
- Unsplash API

## ⚙️ Setup
1. Clone the repository
2. Add your API keys in `script.js`
3. Open `index.html` in browser
