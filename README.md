# 🌤️ Weather Explorer

A simple and aesthetic weather website that lets users search for a city and explore its weather information through a visually engaging interface.

The main highlight of the project is its **dynamic background experience** — when a user searches for a city, the website changes its background according to the searched location, creating a more immersive and city-specific experience.

## ✨ Features

* 🔍 Search weather by city name
* 🌆 Dynamic background based on the searched city
* 🎨 Clean, modern and aesthetic UI
* 📱 Responsive design for different screen sizes
* ⚡ Simple and easy-to-use interface
* 🌍 Supports searching for different cities

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling, animations and responsive design
* **JavaScript** — Search functionality and dynamic background changes
* **Weather API** — Fetching weather information

## 🚀 How It Works

1. Enter the name of a city in the search bar.
2. The website fetches the city's weather information.
3. The interface displays the weather details.
4. The background changes according to the searched city to create a more personalized visual experience.
